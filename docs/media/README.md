The mockups and GIF are generated by [render-github-media.py](../../scripts/render-github-media.py) using Pillow. Fish geometry and colors mirror the native shared rail. The GIF holds the example percentages fixed, as the real fish stays at its quota position while chomping. Regenerate these assets when the actual UI changes.

The promo is marketing artwork created using the **built-in imagegen tool**, not the fallback CLI. It does not replace the application icon or claim third-party endorsement. The generated original was copied into this repository for GitHub use.

## Final promo prompt

> Use case: ads-marketing. Create a polished minimalist landscape promotional banner for the GitHub README of TokenFish, a Windows desktop companion showing Codex and Claude usage. Use a wide 16:9 composition, export as a high-quality raster image. Deep charcoal background #10151C, almost flat with a very restrained fine soft gradient, generous negative space, refined editorial typography. Exact text, spelled perfectly: large title 'TokenFish', smaller line 'Your AI usage, at a glance.', compact understated footer 'Codex + Claude  /  Windows'. Put the title and copy on the left half, visually balanced with two simple geometric arcade fish on the right half eating small circular token pellets along two horizontal rails. The fish are angular flat silhouettes facing right, each with one tiny dark square eye, a diamond tail, an angular almost hexagonal body, and a small V-shaped open mouth. One fish mint #74D9C0, one warm peach #E8AD8B; a smaller lime #DDF87B fish beside the wordmark anchors the brand. Fish should feel like the actual tiny WinUI mascot, elegant and playful, not realistic animals or round Pac-Man circles. Token pellets are sparse tiny mint and peach dots ahead of the mouths; eaten segments behind them are dim. Everything crisp, restrained and beautifully spaced. No screenshots, no app controls, no 3D, no glow, no busy aquarium, no water, no blue waves, no devices, no extra copy, no third-party logos, no watermark. This is promotional artwork, not a replacement application icon.
